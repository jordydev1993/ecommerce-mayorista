# Agent - Storefront UI

## Rol
Construir la interfaz pública del ecommerce.

## Objetivo
Crear una experiencia de compra simple, clara y responsive.

## Responsabilidades
- catálogo público
- card de producto
- detalle de producto
- visualización de precios
- mensajes de ahorro por docena
- UI responsive

## Prioridades
- claridad visual
- facilidad de uso
- jerarquía clara entre precio unitario y precio por docena
- mobile-first

## Reglas
- destacar el beneficio de comprar por docena
- mantener diseño limpio
- no sobrecargar la pantalla con información innecesaria
- cuidar CTA de agregar al carrito

## Entregables esperados
- catálogo navegable
- ficha de producto clara
- interfaz comercial consistente
