# Skill - Commerce Messaging

## Objetivo
Crear mensajes comerciales claros para el pedido por WhatsApp.

## Reglas
- mostrar datos del cliente
- mostrar detalle de productos
- mostrar cantidades
- mostrar docenas aplicadas
- mostrar unidades restantes
- mostrar subtotal por línea
- mostrar total final
- usar formato legible y ordenado

## Buenas prácticas
- evitar mensajes largos y confusos
- usar saltos de línea claros
- pensar el mensaje para quien recibe y prepara el pedido
