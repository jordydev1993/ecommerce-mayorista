# MPC - Ecommerce Mayorista

## Objetivo
Desarrollar un ecommerce mayorista simple con catálogo, carrito, descuento por docena, pedido sin registro, guardado en base de datos y envío por WhatsApp.

## Reglas principales
- No hay pagos online
- No hay registro de clientes
- El pedido se hace sin login
- El descuento se aplica por cada 12 unidades del mismo producto
- Las unidades restantes se cobran a precio unitario
- El cálculo nunca mezcla distintos productos

## Prioridades
1. Correctitud de pricing
2. Flujo de compra simple
3. Panel admin funcional
4. Código modular y escalable

## Orden de implementación
1. Setup
2. Base de datos
3. Catálogo
4. Pricing
5. Carrito
6. Checkout
7. WhatsApp
8. Admin
9. QA
