# Skill - Modular Architecture

## Objetivo
Mantener una arquitectura simple, ordenada y escalable.

## Reglas
- separar UI, lógica y datos
- mantener /lib para helpers y utilidades
- mantener /types para contratos de datos
- agrupar componentes por dominio
- evitar archivos gigantes

## Principios
- una responsabilidad clara por módulo
- reutilización antes que duplicación
- estructura fácil de navegar
