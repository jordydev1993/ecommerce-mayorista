# Skill - Clean UI Commerce

## Objetivo
Diseñar una interfaz clara para ecommerce simple.

## Reglas
- destacar nombre, imagen y precios
- mostrar claramente precio unitario y precio por docena
- usar CTAs visibles
- mantener jerarquía visual
- aplicar responsive mobile-first

## Buenas prácticas
- evitar ruido visual
- simplificar decisiones del usuario
- resaltar beneficios comerciales como el ahorro por docena
