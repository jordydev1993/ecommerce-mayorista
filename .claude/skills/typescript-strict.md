# Skill - TypeScript Strict

## Objetivo
Mantener tipado fuerte y consistente en todo el proyecto.

## Reglas
- usar TypeScript en todos los módulos
- evitar any
- tipar props, funciones, utilidades y datos
- crear types o interfaces claras
- reutilizar tipos compartidos desde /types

## Buenas prácticas
- preferir tipos explícitos
- tipar retornos de funciones importantes
- no dejar datos implícitos si afectan negocio
